## TYPE script

Now what does TypeScript do? Well it's in the name, TYPE script. It literally adds types to JavaScript. This means that `let x = 5;` becomes `let x : number = 5;` We explicitly say that x has to be a number. Is this important or is it just making things harder.

Well I believe that it does a good job at catching any errors before you run the program. The most basic example would be trying to say `x = 'five';`. This wouldn't work because earlier TypeScript was explicitly told x was a number. The way I think of it, TypeScript has built in comments are enforced.

```
function printVar(x: number) : string {
  return `The value is ${x}`;
```
Not only does TypeScript tell you the function takes a number as a parameter and returns a string, it enforces those rules by throwing an error if you try to enter in different types.
